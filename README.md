# The Geographer's Craft - Revival Project

## Project Mission

To revive and modernize **The Geographer's Craft**, a pioneering NSF-funded educational project that taught GIScience and geographic techniques on the web. Originally developed by **Kenneth E. Foote** and **Peter H. Dana** at the University of Texas at Austin (later University of Colorado Boulder), this project was instrumental in defining web-based geographic education in the 1990s.

---

## Background

### What Was The Geographer's Craft?

The Geographer's Craft was an innovative National Science Foundation (NSF) supported project initiated in the early 1990s. It served as one of the first electronic textbooks and laboratory manuals in Geographic Information Science (GIScience), available freely on the web.

**Key Features:**

- Online hypermedia teaching materials
- Problem-based, active-learning approach
- Comprehensive coverage of GIS, GPS, map projections, and coordinate systems
- Student collaboration and web-based projects
- Freely accessible educational content

**Timeline:**

- **Early 1990s:** Project initiated at University of Texas at Austin
- **1994-1999:** Active development and use at UT Austin
- **~1999:** Project moved to University of Colorado Boulder
- **2000-2002:** Continued development at CU Boulder
- **~2005:** Original website taken offline
- **Present:** Content preserved via Internet Archive (Wayback Machine)

## Topics Covered (Original Curriculum)

1. **GIS Fundamentals**
   - Context, concepts, and definitions
   - GIS as an integrating technology
   - GIS in the workplace

2. **Spatial Reference Systems**
   - Global Positioning System (GPS)
   - Map projections
   - Coordinate systems
   - Geodetic datums

3. **Data Quality**
   - Managing error in GIS
   - Attribute accuracy
   - Sensitivity analysis

4. **Professional Practice**
   - Legal issues in GIS
   - Project lifecycle and planning
   - FOIA and privacy considerations

5. **Visualization**
   - Aerial photography and remote sensing
   - Cartographic communication

## Version 2 Modernization Plan

### Technology Stack

- **Framework:** Modern HTML5/CSS3/JavaScript
- **Maps:** Leaflet.js with multiple basemap options
- **Interactivity:** React or Vue.js components
- **Design:** Responsive, mobile-first approach
- **Accessibility:** WCAG 2.1 AA compliance

### Content Updates

| Original Topic     | V2 Updates                                         |
| ------------------ | -------------------------------------------------- |
| GPS Overview       | Full GNSS coverage (GPS, GLONASS, Galileo, BeiDou) |
| Map Projections    | Interactive projection explorer                    |
| Coordinate Systems | Modern datums (WGS84, ITRF, NAD83(2011))           |
| Legal Issues       | Updated privacy laws, open data policies           |
| Error Management   | Machine learning accuracy assessment               |

### New Features

- Interactive coordinate transformation calculator
- Live GNSS position demonstration
- Web-based projection visualization tool
- Case studies with real-world datasets
- Self-assessment quizzes with immediate feedback
