# Project Planning and Lifecycle

**Authors:** Kenneth E. Foote and Shannon L. Crum  
**Affiliation:** Department of Geography  
**Source:** The Geographer's Craft Project

## Overview

This module addresses project management and planning for GIS implementations, emphasizing the System Development Lifecycle (SDLC) and the importance of structured approaches to prevent project failure.

---

## Major Sections & Topics

### 1. The Importance of Project Planning

- Planning is key to preventing project failure
- Managing complex GIS implementations
- Early investment in planning reduces later costs

### 2. The Value of a Problem Solving Approach

**Structured approach:**

1. Problem Definition
2. Information Collection
3. Solution Formulation
4. Selection & Implementation

### 3. Project Lifecycle: An Overview

**System Development Lifecycle (SDLC):**

1. **Analysis** - Understanding requirements
2. **System Design** - Designing the solution
3. **Acquisition and Programming** - Building/buying components
4. **Implementation** - Deploying the system

### 4. Key Aspects of Project Lifecycle

- Setting goals
- Cost estimation
- **Functional Requirements Study (FRS)**

### 5. System Selection as a Compromise

Trade-offs between:

- Speed
- Functional Richness
- Database Size
- Training/Cost

### 6. Planning Schedules and Prototype/Pilot Projects

**Salt River Project Example:**

- Multi-year timeline from decision to pilot system
- Phased approach

**Prototype vs. Pilot:**
| Type | Purpose |
|------|---------|
| **Prototype** | Small-scale version to test design concepts and refine requirements |
| **Pilot** | Full-scale test of a portion of the system (one department/area) to work out "bugs" before total rollout |

### 7. Applying Insights to Research Projects

- Translating industrial project management to academic research
- Better efficiency through structured planning

### 8. Other Planning and Database Issues

- Data quality
- Database design
- Long-term maintenance

## Key Project Management Concepts

### System Development Lifecycle (SDLC)

A structured framework for system implementation:

```
Analysis → Design → Acquisition → Implementation
```

### Functional Requirements Study (FRS)

- Critical phase documenting specific user needs
- Ensures system meets intended purpose
- Foundation for system selection

### Incremental Decision Making ("GO/STOP")

- Risk management strategy
- Evaluate progress at specific milestones
- Decision points after:
  - Feasibility Analysis
  - Functional Requirements Study
- Before committing more resources

### The "Compromise" Matrix

- No "perfect" system exists
- Finding best fit for:
  - Technical requirements
  - Budget constraints
  - Organizational readiness

### AM/FM Reference

- Automated Mapping/Facilities Management
- Large-scale infrastructure projects
- Pioneered lifecycle planning techniques in GIS
