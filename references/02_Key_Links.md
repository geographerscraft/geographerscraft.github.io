## Download Tools

### For Archiving Original Website

**Using wget with Wayback Machine:**

```bash
wget --recursive --no-clobber --page-requisites --html-extension --convert-links --restrict-file-names=windows --domains=web.archive.org --no-parent https://web.archive.org/web/20020710214759/http://www.colorado.edu/geography/gcraft/
```

**Using wayback-machine-downloader (Ruby):**

```bash
gem install wayback_machine_downloader
wayback_machine_downloader http://www.colorado.edu/geography/gcraft/
```
